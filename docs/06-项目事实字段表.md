## 与规则引擎的关系

```text
项目事实（字段 + 值 + 来源类型 + 证据定位）
        │
        ├── strict 规则：来源必须 ∈ {official, project_doc} 且必须有证据 ID
        │                    否则 → 待核实（UNKNOWN）
        ├── assumption 来源：任何规则 → 待核实（UNKNOWN）
        └── 字段缺失/为空      → 待核实（UNKNOWN）
        │
        ▼
  三态判断：通过 / 不通过 / 待核实
        │
        ▼
  四态结论：可继续尽调 / 存在明确障碍 / 资料不足暂无法判断 / 无已发布适用方法学
```

引擎实现见 `src/rules/engine.mjs`；字段录入校验见 `src/services/project-svc.mjs` 的 `upsertFact`。
