# 省域地图本地独立验收

验收日期：2026-10-20。开发由 DSH 完成，Codex 进行了独立原始数据复算、HTTP 和浏览器验证。此文档记录本地结果，不表示云端已升级。

## 本地预览与范围

- 地址：http://127.0.0.1:8922/v2/
- 预览数据库：`data/province-map-review-20261019.db`，由原有本地评审库复制。日调度在此预览实例关闭，避免重复任务。
- 总览新增省域地图，分别展示公开 CCER 项目、区域 CO₂ 排放、全国碳市场纳管排放。包括省份选择、区域分组、年度选择、来源与核算边界、排名和 CSV 下载。
- 项目数量取本平台当前收录快照；排放按指定年度展示。两者不能因同图展示而理解为同年度项目清单。

## 已核验结果

### 公开项目

298 条非演示公开收录记录，按官方登记编号去重后为 237 个项目；无登记编号时以项目 ID 为键。相同项目的阶段标记取并集，不删除历史行，各阶段不可相加。

浏览器显示总览公示项目、项目进度和地图总数均为 237 个。新疆建设兵团等受控别名归入新疆，地图新疆为 13 个，未知省份为 0。该数值只代表此本地快照，不能当作全国实时项目总数。

### 区域排放

来源为 [Carbon Monitor-China](https://cn.carbonmonitor.org/) 的公开 CSV，属于研究估算。覆盖电力、工业、地面交通、国内航空、居民消费五部门，不等于官方全社会温室气体清单，也不是全国碳市场纳管排放。

- 2019—2025 年，每年 29 省，共 203 条有效年度记录。
- 内蒙古、黑龙江在该原始文件中缺少部分部门，不合计成五部门总量；港澳台无此数据。相应地区保持空值。
- 2026 年仅部分月份，未年化为全年。
- 原始单位 MtCO2/day，逐日汇总后乘 1,000,000 转为 tCO2/年。使用独立 Python Decimal 汇总与实现结果对比，203 条最大差异为 0 tCO2。
- 山西 2025 年为 539,495,619.842 tCO2，页面换算显示 5.39 亿吨，保留实际年度和原始证据。

2026-10-20 实际联网采集成功：19,766,558 字节，SHA-256 为 `723709ff6cc610e121d502f0c0aa9adb55aa6531a616cb145109de4e12b0ae52`。与已有原件相同，采集器核对库内完整覆盖后跳过重复写入，只更新检查时间。回执：`data/backups/province-map-20261019/live-collect-result.json`。

### 全国碳市场纳管排放

当前库中尚无可用省级实际排放数值，34 地区均保持空值，不使用配额、履约量或名录企业数代替排放。页面显示“年度未取得”“排放未取得”，名录采集日期另列。

本地名录目前只收录福建 2026 年 84 家企业，其他地区显示“名录未收录”，不暗示现实中没有企业。名录覆盖和实际排放缺口仍需要后续公开来源补充。

### 接口与页面

- 普通登录用户可读取地图及导出 CSV；匿名地图请求返回 401；非法指标返回 400。
- 真实 HTTP 验证逐年比对全部 203 条数值、缺失状态、研究来源标签及导出，12 项检查通过。见 `data/backups/province-map-20261019/real-http-verification.json`。
- 1440px 桌面和 390px 手机宽度检查通过，无整页横向溢出；34 个省级地图选择目标存在，省份切换保留正确详情，项目阶段显示中文。
- 纳管排放视图不借用名录采集日期作为排放数据截至时间，其他视图仍可查看该省当前公开项目。
- 地图底图缓存自阿里云 DataV，来源记录及 SHA 保留在 `web/v2/assets/maps/source.json`。底图来源不代表平台取得新的地图审图号。

## 回归检查

最终回归：115、116、117、118、13、68 六个测试文件共 78 项通过（分别 23、7、8、3、30、7），Codex 独立重跑通过，日志为 `data/backups/province-map-20261019/final-tests.log`。

浏览器终验发现底图异步加载后归属行采集日期未即时更新，已交 DSH 修复，新增首次加载/失败后重试、保留选中与焦点的断言。Codex 重新加载页面后实见采集日期 2026-10-19 与 SHA 前缀 99adfeded522；浏览器未记录控制台错误。验收截图：`output/province-map-overview.jpg`。本地预览标签已保留，临时响应式视口已恢复。

独立测试覆盖了采集总时限包含正文读取、相同 hash 但库内不完整仍补采、真实日历日期、来源 URL 校验、脏数据口径隔离、项目去重及阶段并集等风险。测试使用临时库，不访问付费服务。

## 日更新与后续部署

公开区域数据采集已接入现有日更新链路，固定 HTTPS 来源、并发 1、32 MB 上限、约 90 秒总期限。失败保留历史有效值，内容变化通过修订关系留痕，不因检查日期变化每天生成数百次修订。

本次没有修改云端服务和 GitHub。未来上线应备份云端数据库，部署代码和增量表结构，再对云端当前库运行区域数据导入/采集；不得直接用此本地评审数据库覆盖云端的账户、配置和最新业务数据。本地测试账户只用于验收。

部署到 2 GB ECS 后仍需实测采集峰值内存、任务错峰和回滚；本地性能不作为云端容量结论。当前实现未增加管理员区域数据导入界面，支持 CLI，已有管理员内容维护界面不受此功能影响。
