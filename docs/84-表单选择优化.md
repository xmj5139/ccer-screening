# 84 · 表单选择优化（省份 / 方法学 / 地区 / CEA 行业与年度 / 核算）

> 2026-10-22｜本地实施记录｜未部署、未推 Git、未改生产库、未启动采集或摘要 worker
>
> 目标：把公开页面与后台编辑表单中**有有限选项**的文本框改为下拉；来源、机构、方法学编号等无法保证完整清单的字段改为 datalist 建议，仍允许自由输入；任何下拉都不得改变原有筛选语义，也不得吞掉旧值与 URL 原值。

## 1. 交互约定

1. **筛选下拉**固定保留空值「全部××」；选中空值即清除该 query 参数。
2. **当前 query 值不在选项表时**，仍生成一个 `selected` 的「（历史值）」选项，不静默改为「全部」。
3. **省份/地区选项**保留：`全国`、六个电网区域（华北/东北/华东/华中/西北/南方）、34 个省级行政区、`新疆生产建设兵团`，以及库内实际出现过的历史写法。
4. **来源/发布机构**没有完整清单，使用 `<input list>` + `<datalist>`，建议来自真实公开数据，输入不受限制。
5. **方法学编号**在后台编辑表单使用 datalist：目录内可选，目录外可手填；公开项目筛选使用下拉，库内历史编号全部保留。
6. **管理员编辑表单**只把白名单中的有限枚举改为下拉；URL、日期、数字、标题、摘要、备注、证据定位等保持原控件，URL 原值原样回填。
7. 所有 option 的 value/label 与 datalist 建议都经 HTML 转义；未知旧值也先转义再输出。

## 4. 接口与共享工具

### 4.1 新增只读接口

`GET /api/v2/meta/form-options`

- 登录用户可读，不写库、不读凭据、不启动任务。
- 聚合：
  - 省份目录（全称/短名/分组）、全国、电网区域、兵团；
  - 公开项目实际省份、城市、方法学、领域；
  - CEA 文件行业/年度、名录省份/行业/年度、意向年度、发文机构；
  - 排放因子地区/口径/年度 facets；
  - 政策机关、研报发布方、CEA 发文机构、项目业主等来源建议。
- 单个表缺失只让对应列表为空，不影响其它选项。

### 4.2 共享工具

`web/v2/form-selects.js`

- `selectOptionsHtml`：生成「全部」+ 选项 + 未知当前值；统一转义。
- `datalistHtml`：生成建议列表；当前值也进入建议。
- `editFieldControl`：后台编辑字段控件（下拉 / datalist / URL / 日期 / 数字）。
- `loadFormOptions` / `fallbackFormOptions`：真实选项读取与离线兜底；缓存 60 秒，过期后下次读取刷新，失败可重试。不会自动启动采集。
- `normalizeOptions`：字符串或 `{value,label}` 统一、去重、丢弃空值。

`web/v2/ui.js` 的 `filtersBar` 同步支持 `select` 与 `datalist` 两种字段，旧调用参数仍兼容。

## 6. 保留限制

1. **选项随库变化**：CEA 年度、行业、项目省份/方法学都来自当前库；库内尚无数据时不会编造选项。旧 URL 中的未知值仍以「历史值」显示，可继续筛选。
2. **项目省份是精确匹配**：下拉中的全称与库内实际历史写法都列出，但没有增加“短名→全称”的隐式映射；选择哪个值就原样提交哪个值。兵团按独立值保留，不擅自并入新疆。
3. **统一检索地区**：使用下拉建议并允许自由输入，保留未列出的城市与地区片段查询；后端地区匹配逻辑未改。
4. **来源/机构清单不完整**：datalist 只做建议，不阻止输入新机构；服务端仍按原来源字段筛选。
5. **管理员编辑中的 URL**：保持 `type=url` 文本框并回填原值；服务端仍执行 http(s) 校验与脚本载荷拦截。
6. **后台配置项**：密钥、超时、额度、路径、ID 等保持手填，未做下拉；这是安全与可运维性要求。
7. DSH 的交付未包含浏览器验收；Codex 已补做桌面、390px 手机与后台编辑核验，见第 7 节。
