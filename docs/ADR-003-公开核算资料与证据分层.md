# ADR-003：公开核算资料与证据分层

2026-10-15，已实施。

排放因子、通用核算标准及CETS公开政策问答存入独立的accounting资料表；不复用CCER正式项目计算的因子表，不解除既有方法学门禁。界面沿用八个主模块，在“碳计算与因子”中提供六个子页，CEA清结算使用独立来源对照。

数值计算由确定性函数执行，显式选择因子、地区、年度及单位。目标年度不一致需用户明确接受参考年。不保存用户的项目或计算输入，不由模型生成公式或官方数值。电力CO2排放不自动视为CO2e或CCER签发量。

资料完整性以逐页成功覆盖判断，复用原生PDF文本和百度OCR；原件、正文、页码、哈希与模型核验记录分开保存。模型仅核对来源一致性。缺少明确一致结论、出现不可定位引用或证据不完整均不得标为verified。发布日期与成文日、栏目分类与公文文种分别处理。

公开抓取先尝试限定域名的HTTP，再使用已配置抓取连接。服务请求成功不表示目标网站成功：来源HTTP412、空markdown、加载占位页、登录页均不能生成正文。CETS只收公开页面；栏目宣称数量与实际取得数量分列，未取得分页不推断补齐。公开问答保留原文及日期缺失提示，不保证历史答复已按新规更新。

新增采集接入每日06:30任务，每批共享120秒上限、单并发、异步202任务与轮询，保留轮转游标、缓存及修订。每日尝试最新中碳登日报及四个CETS栏目；剩余预算轮转行业规范、因子原件和门户探测。超时标partial，有实际失败不得标成成功空扫描。中断作业可自动恢复重试。

中碳登与交易所同日量额分列对照，不重复相加；日报均价不覆盖CEA综合收盘价。官方因子原件变化且数值冲突时，自动交模型核对并保留原值、原件及差异，不静默覆盖历史记录。

管理员可以上传本机PDF补足标准正文；文件名、20MiB上限、PDF文件头、角色及存储路径均由服务端校验。补充件与官方原件哈希是否相同独立标记，模型一致性结论不等于文件具有官方来源身份。云端发布只更新代码并做增量迁移，不复制本地测试库或凭据。
