# ADR-002：CEA 独立行情与共享公开证据

状态：Accepted。日期：2026-10-14。

## 背景

现有系统整合CCER公开信息。CEA交易具有年度配额标的、综合指数与多种交易方式；企业名录、配额分配和履约节点也不同于CCER项目方法学。旧CCER trade_daily中的累计值不能和CEA累计值共用。

## 决策

CEA日行情和年度标的元数据独立存储，展示官方指数与程序计算的全方式均价两个字段。政策、研报、原文快照、后台已配置搜索/抓取/大模型、会话身份和审计能力尽量共享。允许独立CEA专题，现有页面只提供品种切换或快捷入口。成本工具只计算临时情景。

2026年综合指数采用CEA25权重1的官方编制方案；按行情版本标记历史序列。全文与引文核验优先，AI结论只作为单独的证据一致性状态，不覆盖官方原数。名录身份、公开交易意向与真实成交分开统计。

## 考虑的替代方案

- 把CEA直接塞进CCER交易表：初期改动少，但会引入累计口径、价格字段和日历混用，放弃。
- 为CEA建立第二个独立应用：可隔离业务，但重复账号、凭据、采集和维护成本，放弃。
- 依赖搜索摘要及模型生成行情：缺少来源全文和确定性检查，不具备验收条件，放弃。

## 后果

增加增量数据库结构和数据源接入，但保留现有CCER功能。新来源可能动态渲染或不完整，因此空值与缺口状态是正常业务结果。部署仍使用现有轻量Node/SQLite，控制任务耗时和API配额。升级前后必须验证账号、密钥、历史交易与附件均保留。
