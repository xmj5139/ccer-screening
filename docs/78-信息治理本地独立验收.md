# 信息治理本地独立验收

验收日期：2026-10-21。开发由 DSH CLI 分两轮完成，Codex 独立复核并修复验收中发现的问题。本轮仅交付本地版本，尚未部署云端或推送 GitHub。

## 已交付范围

- 采集与核验闭环：研报动态、政策文件、方法学版本、CEA 文件、标准规范、公开资料/问答、公开项目，共七类资料；分别记录发现、正文/附件、解析/OCR、摘要、核验阶段。
- 每日任务接入有界治理 worker，带租约、尝试上限、退避和输入变化检测。摘要与核验按实际输入签名判断是否失效，读页面不会清空退避；完成处理不等于核验通过。
- 历史补采支持日期窗口、来源、查询词、预算、暂停/继续/取消及重启恢复；日期范围实际发送给博查。
- 方法学版本时间线、关系候选及有原文依据的比较。关系必须绑定来源、逐字引文和当前有效核验，不能根据相邻编号或模型记忆确认。
- 顶栏统一检索公开资料，支持中文检索及筛选；普通用户可以检索，治理及补采仅管理员访问。公开项目按逻辑项目去重，避免与总览计数不一致。

## 验收期间修复的可靠性问题

独立测试覆盖并促成修复：过期摘要/核验签名、未来时间戳绕过、重试退避被读操作重置、分页边界、同 ID 跨类型串数据、每日任务绕过预算、版本关系误确认等问题。

Codex 另修复来源 URL 比较：保留 `fileId/id` 等查询参数，避免把同一路径不同文件当成同一证据；关系引文必须指向目标版本，不能用“替代 V00”证明“替代 V01”。测试 126 和 140 及九文件回归通过。

## 边界与运行方式

- 历史日期补采目前覆盖公开内容（研报/动态/观点/公告）；其他资料类型使用其专用采集能力，未伪装成支持统一全量补采。当前搜索连接没有声明分页能力，不能保证穷尽网站历史记录。
- 因子、行情、企业名录沿用结构化核对，不为每家企业新增模型调用。结构化项目不适用的 PDF/OCR 阶段明确跳过。
- 搜索为有界数据库检索，存在结果及分页上限，不是无限全文搜索引擎。
- 未获取原件、正文不完整、服务失败或证据冲突继续明确标记；本轮没有把全库资料批量强制改成“已核验”，也不代表全部历史缺口已解决。
- 本地预览：`http://127.0.0.1:8925/v2/`。使用独立快照 `data/backups/information-governance-20261021/local-review.db`，关闭每日采集与收盘定时任务，避免评审页面触发持续外部调用。其数据来自本地历史快照，并非云端最新实时数据。
- 原数据库、账号、密钥与云端服务未改动；预览库含敏感服务配置，不得提交 Git 或公开分享。源码备份为同目录 `code-before.zip`。

用户复核本地版本后，再进行云端数据库备份、部署及线上回归。
