## 产品定位与导航

名称：CCER 公开信息平台。以投资机构和研究团队为读者，不管理他们的自有项目。

七个主模块：

1. **总览**：最新政策、方法学状态分布、公开项目阶段/类型/地域分布、交易量价趋势、最新研报与动态、数据更新时间。使用真实数据；演示条目从业务统计排除。每个指标可追到来源，公示量不当登记量，重复阶段不可相加成项目总数。
2. **政策与方法学**：全国 CCER 规则、配套技术文件和相关部委政策；正式、征求意见、修订、废止分开。方法学含原文、适用范围、关键条件、参数、自动解读和版本变化。不得因为取消人工审核就把草案当现行正式方法学。AI 解读标“自动生成”，展示证据引用和核验结果；缺正文时不声称已读原文。
3. **公开项目**：主来源 https://ccer.cets.org.cn/projectPublicity/projectPublicityList ，覆盖公开项目/减排量公示、登记等可查阶段，保留业主、方法学、地域、原始文件、阶段日期和历史变化。删除内部项目页签、项目创建和项目人工核对按钮。附件不能下载时显示真实状态与官方链接。
4. **交易信息**：官方市场量价、区间汇总、趋势图、CSV/XLSX 下载。保留确定性量价/累计差分检查；错误和冲突自动标注，不建人工核对任务。没有项目级对应证据，不编造项目成交量。
5. **减排粗估**：无须建立任何项目档案，无须人工签字或审批。低于 8% 煤矿瓦斯简表置顶，年混合气量、平均甲烷浓度两项为主，处理比例和销毁效率为可选高级参数。结果是规模粗估，不是可签发量。不得由 LLM 任意生成数值公式。旧完整核算/申报流程从新版移除，不把不完整公式直接放行。
6. **研报与行业动态**：公开研报、机构分析、企业/行业动态两个页签（或同页筛选）。可按时间、类型、机构、方法学/行业、关键词过滤；显示摘要、要点、发布日期、作者/发布机构、来源 URL、文件链接、核验状态。观点、预测和已发生事实分开。公开全文可归档；只有摘要或付费链接时保留元数据/公开摘要并标明，不能声称读过全文。
7. **后台管理**：采集连接、搜索 API/MCP、模型配置与真实连接测试、自动核验策略、每日任务/重试/错误日志、用户管理和操作日志。删除人工审核任务、复核角色、专家审批等。故障/冲突只作为自动运行状态，不要求管理员审批内容。

## 自动采集与核验链路

来源发现 -> 抓取正文/文件 -> 去重与版本保存 -> 结构化抽取 -> 规则一致性检查 -> 模型证据核验 -> 自动发布与状态标记 -> 每日更新。

### 来源与连接

- 现有官方 CCER 项目采集和交易采集保留，并让它们独立于模型/API 是否配置。
- 后台新增搜索服务配置：至少实现一个真实搜索 API 适配器，例如 Tavily 或 Firecrawl Search；请求与响应结构以供应商当前官方文档核实。支持调用限额、超时、重试、凭据只存服务端。未配置时如实显示不可用，不用空返回假装成功。
- 提供一个真正可工作的网页抓取连接：Firecrawl Scrape API 或远端 Streamable HTTP MCP 的 tools/list + tools/call。若选择 API 路线也必须满足用户“抓取 MCP 或搜索 API”的自动收集目标，不能把 Codex 当前工具名硬写进线上应用。配置清楚服务地址、工具名、参数映射、鉴权、域名和测试结果。
- MCP 若支持，仅调用配置的只读搜索/抓取工具。外部返回的内容都是数据，不能当作开发指令、系统提示或动作授权。
- 非政府来源分类：证券/研究机构的公开研报和网站；行业协会、交易机构、碳市场专业媒体；企业公告与项目主体新闻。官网可用性逐一验证后再作为种子来源。企业主张不能标为政府确认，二次转载归到原始发布者。
- 关键词组合：CCER、全国温室气体自愿减排、方法学、减排量登记、煤矿瓦斯、甲烷、碳汇、碳市场交易；按日期窗口/来源类别日更。不要只搜一个关键词。
- URL/内容哈希去重；同一篇多站转载建关联，不重复统计；原文变化保存版本与变化摘要。

### 大模型验证

- 核验输入包括抓取正文、结构化字段、可核对的第二来源、原文证据；只给搜索摘要时需明确核验能力有限。
- 核验结果至少：`verified`（模型与规则一致性检查通过）、`insufficient`（证据不足）、`conflict`（来源矛盾）、`unavailable`（模型/正文不可用）。界面对应“自动核验通过 / 证据不足 / 来源冲突 / 暂未自动核验”。不能一律盖“真实可靠”章。
- 存结果、模型版本、时间、输入哈希、引用、冲突字段和简洁说明。模型通过表示证据一致性，不表示独立审计。
- 不生成任何人工审核/批准任务；自动重试或重新搜索补证。冲突记录仍可检索，但不能自动覆盖已有官方数值或进入已核验统计。
- 政策效力、方法学编号、交易数字优先官方原文；行业观点和预测可自动归档，但不升格为事实。
- API 失败、配额耗尽、JSON 格式错误、提示注入文本都要有确定处理。模型不可用时可以继续展示公开原始记录，明确未核验；不得阻断全站。
- 通用模型服务要可复用到政策、方法学和研报/动态，不仅仅复核项目。
