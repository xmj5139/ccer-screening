# 企业名录采集修复记录

日期：2026-10-20。对应要求：`docs/64-全国碳市场企业名录补采要求.md`。本轮只完成 DSH 侧采集器必要修复与测试；真实数据采集、逐表规范化、最终导入和部署由 Codex 独立执行。

## 一、修改文件

- `src/services/cea-parse.mjs`
  - 新增名录年度识别 `detectEntityListYear`：只认「重点排放单位名录/名单」标题及其前两行中**最靠近名录标识**的年度；发布日期、2025 年工作通知引用不当作名录年度；多个不同名录年度返回冲突/缺口。
  - 新增真实 HTML `<table>` 解析：按表头列名取值，支持列顺序变化；按各表标题和表内「发电行业/钢铁行业/水泥行业/铝冶炼行业」分节识别行业；不把行业、地区、备注拼入企业名称。
  - 完善 PDF/纯文本解析：以信用代码为锚点，支持换行公司名（如「…有限公 / 司」）、换行地区（如「凉山彝族自 / 治州」）、备注换行（自备/电厂）、多页表头；2511 等国民经济行业分类代码不作为实际纳管类别。
  - 缺代码留空并保留 `raw_credit_code`；校验位异常只标注，不修改原文、不编造代码。
  - 正式名录标题 + 可识别表头 + 企业名称/代码时允许 1~2 行小行业名单；无表头兜底仍要求至少 3 行，未放宽全局 `minRows`。
  - 拦截地方试点、仅报告/核查、拟纳入/征求意见、采购/招标/中标公告等非正式名录页面。
- `src/services/cea-collect-svc.mjs`
  - 默认来源改为轮换：未尝试优先 → `last_attempt_at` 最旧优先 → `priority`/`code` 稳定排序；每批仍最多 4 个，共享总 deadline，未新增并发或计划任务。
  - 显式 `codes` 严格按指定顺序，不轮换。
  - 增加 `selection`、`sources_total`、`sources_selected`、`sources_attempted`、`sources_not_attempted`、`deferred_sources` 等如实标记；剩余来源未处理时 `truncated=true`，任务状态不为 success，不宣称全部完成。
  - 接入 `sourceEntityMeta.sector`，支持单一行业来源登记补充 sector。
  - 解析成功后写入既有 `cea_entity_parse_result:<code>` cache 契约（hash/rows/complete/parser）；同一原件 hash 未变时复用，不重复写入。
  - 存在 open parse gap 时不靠旧缓存宣称恢复；成功解析后按既有缺口机制结清 fetch/parse 缺口（记录保留）。
  - 缓存失效需重解析时，保护既有完整字段：不用缺代码/缺地区/更短名称的弱解析覆盖完整企业字段；不删除历史企业、不标退出。
- `src/data/cea-sources.mjs`
  - 接入 `CEA_ENTITY_PUBLIC_SOURCES`（只接线、按 code 去重、保留 Codex 登记的 URL/白名单），保留福建 2026 来源。
  - **未修改** `src/data/cea-entity-public-sources.mjs` 的内容；该文件由 Codex 持续补入真实来源。
- `test/119-v2-cea-entity-directory.test.mjs`（新增）
  - 覆盖默认轮换、显式 codes 顺序、年度与发布日期区分、年度冲突、HTML 不同列顺序/多表行业、PDF 换行公司名/换行地区、小行业 1 行、地方试点/仅报告拦截、同源 hash 缓存与弱解析保护、累计标记。
  - 使用 `setupV2()` 独立临时库和本机回环 stub；不调用真实付费服务，不触碰生产/预览库，不修改凭据。
