## 3. 数据与口径

### 3.1 项目视图

- 来源：现有 `public_project` 表，不新增项目表。
- 口径：`COALESCE(is_demo,0)=0`；按 `registry_project_no` 去重，缺失登记号时按项目 ID；重复行阶段标记取并集。
- 指标：公开项目数、项目登记数、减排量登记项目数。
- **不汇总登记减排量 tCO2e**：现有批次字段不足以证明同口径且无重复，也不用业主预计量替代。接口 `data_quality.registered_reduction_amount` 固定为 null，并返回说明。
- 未知省份：保留原始文本单列（空值显示「未标注省份」），不按项目名、城市名或地址猜测；CSV 也保留 unknown 行并标注。

### 3.2 排放视图

- 范围：`region_co2`（区域 CO₂）、`national_ets`（全国碳市场纳管排放）。
- 只接受/展示：有明确省份、范围、年度、`unit=tCO2`、方法/边界、来源名称/URL、`source_kind`、原文 `excerpt` 的有效 active 记录。
- `value_tco2` 是基准值；页面和 CSV 的展示在“吨/万吨/亿吨”之间自动换算，底层字段仍为 tCO2，不混 tCO2e。
- 同一省/范围/年度可以有多个 `dataset_key`；接口按 dataset 选择，返回 `dataset_options` 和每数据集覆盖年度。**不静默相加、不覆盖**。
- 默认选择：优先覆盖省份最多的年度，再选该年度覆盖最多的数据集；并列时官方优先、最近入库优先。界面始终显示实际年度/数据集/来源类型。
- 缺失：`value=null`、`missing=true`、`display=未取得`；真实 0 保留 `value=0`、`missing=false`、`zero=true`。前端分别用浅绿零值和灰色斜纹表示。
- 已披露合计：只汇总当前数据集实际覆盖省份的值，标签明确写“非全国排放总量”；不计算“排放 − CCER”净排放。
- 地方试点数据不进入 `national_ets`；配额/履约量不当作排放量。

### 3.3 全国碳市场名录

- 来源：现有 `cea_entity`，仅用于名录数量，不作为排放值。
- 按 `list_year` 展示最近名录年度；同一 `entity_key` 在年度内去重；`all_years_count` 给出跨年去重后的企业数。
- 前端明确提示：名录数量不代表已披露排放的覆盖率，也不等于买家数量或企业盈缺。
- 本次没有导入新的真实名录/排放数据。

## 4. Schema

`region_emission`（`src/db/schema-regional.sql`）：

| 列 | 说明 |
|---|---|
| `id` | `REM-...` |
| `province_code` / `province_name` | 六位省级代码/规范全称 |
| `scope` | `region_co2` 或 `national_ets` |
| `year` | 数据年度 |
| `value_tco2` | 基准排放量，CHECK ≥ 0 |
| `unit` | CHECK 只能 `tCO2` |
| `methodology` / `boundary` | 核算方法/边界，必填 |
| `dataset_key` | 数据集/口径键 |
| `source_name` / `source_url` / `source_kind` | 来源；`source_kind` 仅 `official/research` |
| `published_at` / `collected_at` | 来源发布日/入库时间 |
| `excerpt` | 原文证据片段 |
| `snapshot_hash` / `content_hash` | 来源快照哈希（可空）/幂等内容哈希 |
| `verification_status` | 固定从 `source_recorded` 开始，不自动变“官方核实” |
| `status` | `active/superseded` |
| `revision_of` / `revision_reason` / `superseded_by` / `superseded_at` | 修订留痕 |
| `entered_by` | CLI/管理员来源 |

约束与索引：

- 部分唯一索引 `(province_code, scope, year, dataset_key) WHERE status='active'`：同省/范围/年/数据集最多一条当前记录。
- 查询索引：`(scope, year, dataset_key, status)`、`(province_code, scope, year, status)`、`(dataset_key, status, collected_at)`。
- 迁移幂等：`CREATE TABLE/INDEX IF NOT EXISTS`；`schema_version_regional_applied` 记录已应用，`schema_version` 保持 2.7.0。
- 同一 `dataset_key + scope` 的来源类型/来源名称/方法/边界必须一致；不一致时导入整批拒绝，要求换 dataset_key 或先确认口径。

修订行为：内容哈希相同则跳过；内容变化时旧 active 行标记 `superseded`，新行写入新值并通过 `revision_of` 指向旧行；不 UPDATE 历史值。

## 5. API

### 5.1 地图

`GET /api/v2/overview/region-map`

权限：登录会话用户（viewer/analyst/researcher/admin）可读；匿名由服务端统一 401。v2 未就绪 503。

查询参数（严格白名单，未知参数 400）：

| 参数 | 说明 |
|---|---|
| `metric` | `projects`（默认）/`registered_projects`/`reduction_registered_projects`/`region_co2`/`national_ets` |
| `year` | 排放视图的实际年度；项目视图传 year 返回 400 |
| `region` | 七大区域或 `港澳台`；只用于排名/导出，不改变全国底图 |
| `domain` / `methodology_id` | 必须是公开项目库中存在的值；只作用于项目数 |
| `stage` | `project_public/validated/project_registered/reduction_public/verified/reduction_registered` |
| `dataset` | 排放视图的数据集键；必须是该范围实际存在的 active 数据集 |

非法 SQL 片段、任意 URL、未知 metric/stage/region/dataset、未来年度、无数据年度均返回 400；查询全部使用参数绑定，stage 用固定列白名单。

返回要点：

- 固定 `regions: 34`（`code/name/short_name/group`），每地含 `project_count`、`registered_count`、`reduction_registered_count`、`ets_directory`（年度/数量/跨年去重）、`emission`（所选值/单位/方法/边界/来源证据）、`samples`（最多 6 个公开项目）、`missing/zero`。
- `year_options` 来自实际 active 排放记录；`dataset_options` 为所选年度的数据集及覆盖省份数；`source` 为数据集级来源，`directory_source` 为名录代表来源。
- `coverage` 包含 `as_of/project_as_of/emission_as_of/directory_as_of` 与三个口径说明；`unknown` 分项目/名录；`totals` 明确“已披露合计（非全国排放总量）”；`notes` 与 `data_quality` 说明 0/缺失/未汇总减排量。
- `views`、`submetrics` 供前端渲染；`generated_at` 为响应生成时间。

### 5.2 导出

`GET /api/v2/overview/region-map/export`

- 查询同地图，另加 `format=csv|xlsx|json`（前端当前只用 CSV）。区域分组生效时只导出该分组；否则导出 34 地区 + 未知省份项目行。
- 使用现有 `export-svc.buildExport`：CSV 公式注入前缀、附件文件名、sha256、`x-export-rows`、导出审计（`export_log` + `audit_log`）。
- 列：省份、省份代码、区域分组、指标键/指标、value、unit、year、scope、method、boundary、source_url、source_name、source_kind、verification_status、excerpt、published_at、collected_at、as_of、missing、missing_reason、dataset_key、名录年度/数量、项目数/登记数/减排量登记项目数、备注。
- 缺失省份 value 为空字符串、missing=1；真实 0 为 `0` 且 missing=0；项目视图的未知省份行 `province_code=UNKNOWN`，备注“未计入 34 地区”。

## 6. CLI

```powershell
node scripts/regional.mjs status [--json] [--temp]
node scripts/regional.mjs import --file=<records.json|csv> [--format=json|csv] [--dry-run] [--actor=<name>]
```

- 默认库沿用 v2 脚本的 `data/ccer_v2.db`；要指向实际库必须显式设置 `CCER_DB_PATH`。`initV2Env` 会拒绝 `data/ccer.db`。本轮测试使用系统临时库。
- JSON 支持数组或 `{ "records": [...] }`；CSV 支持中英文表头（如 省份/scope/年度/value_tco2/单位/来源链接/原文证据）。
- 必填：可识别省份、scope、year、value_tco2、unit、methodology、boundary、dataset_key、source_name、source_url、source_kind、excerpt；`province_code` 可作为 `province` 的替代。
- 校验：年份 1990–当前年；数值有限且 0–1e12；unit 只 `tCO2`；source_url 仅 http(s) 且拒绝本机/内网；official 必须 https + `.gov.cn`/`cets.org.cn` 域名；excerpt ≥12 字且含排放/CO2/单位关键词；拒绝未来年度/未来发布日/未知字段/不一致省份代码与名称。
- 任一行失败整批不写；dry-run 不写库；成功后写 `audit_log`，修订保留历史。
- 管理员后台的省域排放管理/单条编辑 UI 本轮未做（见限制），CLI 为可用入口。

## 10. 真实与模拟

**真实**

- 本地 DataV 底图文件及 hash/采集时间；`source.json` 与文件 hash 一致。
- 临时库中的项目/名录/排放测试记录由测试显式插入，来源标记为“测试临时数据（非真实）”。
- API、权限、参数校验、CSV 导出/审计、CLI、日更只读检查、前端 SVG/HTML 渲染函数。
- 生产代码路径读取现有 `public_project`/`cea_entity`；没有向实际库写入。

**模拟/未包含**

- 本轮没有导入任何真实省级排放数值；实际库的地图排放视图在 Codex 导入前应为“未取得”，不是 0。
- 测试中的排放值（0、123456789、5000 等）全部是临时库合成值，不得当作真实数据。
- 没有自动下载 CEADs 文件；没有调用付费 API；没有用模型生成数字。
- 没有做管理员后台的省域排放管理 UI/单条编辑；没有做真实浏览器验收。
