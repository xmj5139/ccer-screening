## Codex 最后修复

- 新公告从官方列表发现后直接抓取正文、保存快照、写入可浏览政策库，并触发自动核验。重复采集不重复入库，不创建人工任务；公告效力不自动猜成“现行有效”。
- 排除深层 index 栏目页和 APP 产品页；存量误收条目标记为来源归档，保留原文留痕，不计文章数量。
- 事件日期和网址日期不能直接成为发布日期。无法取得明确发布时间时显示未披露。原误填日期保留备注。
- 总览、页首及后台内容状态按当前公开数据统计；演示核验冲突、历史领域签字和旧因子流程不进入现行总览。
- 日期时间统一显示北京时间；总览指标说明可展开，桌面卡片重新排列，手机页首与交易页长网址溢出修复。
- 修正 Windows 主密钥初始化的输出捕获、系统模块路径与账户 SID 检查；真实隔离目录完成 ACL 设置及回读验证，复用不会覆盖密钥。
- 低浓度瓦斯粗估支持 m³/年及万 m³/年，清除页面中的接口字段说明，保留真实单位换算和计算过程。
