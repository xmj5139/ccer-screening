## 1. 交付结论

1. **中文全文索引**：新增可重建的 SQLite FTS5 索引，中文连续串预切为双字词并在串尾补单字，英文/编号保留 `-_.`。统一检索在索引完整时（含空查询浏览）使用 `mode=fts5`，总数来自真实 `COUNT`，600 条记录可翻到第 12 页；索引未构建/损坏/查询失败时回退既有 LIKE 检索并显示 `mode=legacy_fallback` 与真实原因。后台可按有限批次重建/增量刷新，普通用户不能写索引。
2. **用户关注**：新增按 `user_id` 隔离的关注规则、站内信息流与已读游标。支持关键词、地区、行业、方法学编号、内容类型组合；同文转载按事件组合并但逐条保留来源；正文实质变化后已读自动失效。入口放在现有「研报与行业动态」页内，不新增一级导航。
3. **PDF 表格 worker**：新增真实可执行的 `python + pdfplumber` 独立进程，接受受限原件/管理员上传/OCR 治理归档路径，输出物理页码、表序号、行列、单元格文本、成功/失败页与真实 coverage。严格文件大小、页数、超时、单并发、输出上限与 realpath 路径边界；扫描空页只标 `no_text_layer/empty`，不推断“零家企业”。后台有真实操作入口，普通用户不能触发解析写动作。
4. **第一阶段独立验收修正**：发布日期只接受`发布日期/发布时间/发布日/公布日期/生成日期/印发日期/发布于`等明确标签；纯落款、`日期+印发`、`日期+发布` 不再接受。生效日期只接受`施行日期/实施日期/生效日期`或`自……起施行/实施/生效`。阈值必须同时核对数字附近的单位与方向，`低于8%` 不能支持 `8吨` 或 `高于8%`。地区/行业字段改为“仅正文提及”，API、页面和模型提示词都明确非官方适用范围。

## 3. Schema 与迁移

`schema-intelligence2.sql` 只使用 `CREATE TABLE/INDEX/TRIGGER IF NOT EXISTS` 与 `CREATE VIRTUAL TABLE IF NOT EXISTS`，不修改、不删除既有表/列/数据：

- `search_index_doc`：实体类型/ID、类型、原始 payload、来源 hash、过滤列、时间；
- `search_index_fts`：FTS5 外部内容表（`content='search_index_doc'`），触发器同步 insert/update/delete；
- `search_index_meta`：版本、最近构建/完整构建、文档数；
- `user_follow_rule` / `user_follow_read`：规则与已读游标，均以 user_id 为所有权键；
- `pdf_table_job` / `pdf_table_page` / `pdf_table`：任务、逐页结果、表格行列/单元格。

`db.mjs` 在 v2.10 第一阶段之后执行本文件，写入 `schema_version_intelligence2_applied` 并把 schema 标为 `2.9.0`；重复迁移幂等（`test/10` 通过）。`v2-guard` 缺表时返回 503，不会静默运行。

## 4. 中文 FTS5 索引

入口：`search-index-svc.mjs`。

### 4.1 切分与查询

- 先做 NFKC、全角/破折号归一，再按字符扫描；
- 中文连续串：输出全部双字词，再在串尾补单字（单字查询可用，且不打断双字词的相邻位置）；
- 英文/数字/编号：整体保留，并额外输出去掉 `._-` 的 compact 形式；
- FTS5 使用 `unicode61 tokenchars '-_.'`；查询词全部加双引号，用户输入不进入 MATCH 语法；
- 中文多字词按双字短语查询，例如“瓦斯”命中双字 token，“甲烷回收”按 `"甲烷 烷回 回收"` 短语命中；
- `CCER-10-001`、`CCER—10—001—V01` 等编号可精确命中。

### 4.2 可重建、增量与 hash

- `search_index_doc` 每行保存 `source_hash = sha256(type|entity_id|payload)`；
- `buildSearchIndex({types,max_docs,offset,force})` 按类型读取公开实体，未变化行 `skipped`，变化行 `updated`，新行 `inserted`；
- 完整处理某类型时才清理已不符合公开口径的旧索引行（删除/演示/转载/归档/失败等）；
- 管理覆盖层（`admin_revision`）只读合并进索引 payload，不 UPDATE 业务表；覆盖层变化会改变来源 hash，后台编辑后同步单条刷新（索引完整时），结果带 `manual_revision/manual_fields`；
- 项目类型先按 `registry_project_no` 聚合、阶段取并集，再索引，与总览/地图一致；
- 后台 `POST /api/v2/admin/search-index/rebuild` 有限批次；每日 content 步骤只在索引已完整构建时增量刷新 300 条/类型，避免隐式全库重建；
- `content_item` 入库/更新在索引完整构建后走单条增量刷新（按 id 重算 payload/hash）；其它公开类型由每日/后台批次刷新；
- 查询只 JOIN 索引与 FTS 表，不在查询时重建。

### 4.3 总数、分页与回退

- `total` 来自索引真实 `COUNT`，不是旧版“单类型扫描 400 条后的列表长度”；
- 600 条测试可翻到第 12 页（50/页），两页无重复；旧记录（2019）可通过两字词、编号和日期窗口命中；
- 分页 offset 上限提升到 10000；超过上限仍显示真实总数，但提示缩小范围；
- 索引未构建、FTS 表损坏或 MATCH 失败时回退 `searchLegacy`，返回 `mode=legacy_fallback` 与 `fallback_reason=index_not_ready/index_unavailable/index_query_failed`；失败不当无结果。

### 4.4 保留的筛选/排除口径

- 类型：政策、方法学、公开项目、研报动态、CEA 文件、排放因子、企业名录；
- 内容排除：`is_demo=1`、`duplicate_of`、非 `article` 归档、`failed_fetch`；
- 政策排除 `duplicate_of`；因子只索引 `is_current=1`；项目排除 `is_demo=1`；
- 来源、来源类别、地区、日期过滤按原类型支持范围应用；不适用类型不被静默清空，`filter_notes` 说明；
- XSS 标题以纯文本返回（沿用统一检索的 esc 约定）。

## 5. 用户关注与站内更新

### 5.1 规则

- 字段：名称、关键词、地区、行业、方法学编号、内容类型、是否包含更新、启用；
- 组合口径：同一条规则内不同字段 AND，同一字段多个值 OR；
- 至少一个条件；最多 20 条规则、20 个值/字段、60 字符/值；
- 请求体中的 `user_id` 一律忽略，保存/更新/删除/按规则读取都校验 `row.user_id === ctx.user.id`；他人规则 403，不存在 404。

### 5.2 信息流

- 扫描最近 300 条公开内容（排除演示、转载副本、归档、抓取失败）；
- 命中理由可解释：关键词/地区提及/行业提及/方法学编号/内容类型；
- 事件组（同文不同 URL）合并为一张卡，`sources` 逐条保留；转载副本不重复展示；
- 展示最近内容版本的 `change_kind/change_summary`（首次收录/正文实质变化/附件变化）；
- `unread` 依据当前正文 hash 与用户已读游标比较；正文变化后自动重新未读；
- 支持 `unread_only`、`rule_id`、分页；全部已读只处理当前信息流，不越权处理他人。

### 5.3 页面

- 入口在现有「研报与行业动态」页内，不新增一级导航；
- 卡片显示规则数、未读数、规则表单、信息流、命中理由、来源数、标为已读/全部已读；
- 提示明确“提及不等于官方适用范围”，已读游标记录读取时正文版本。

## 6. PDF 表格 worker

### 6.1 真实后端与样本结果

- 后端：本机 `python` + `pdfplumber 0.11.9`（已由 Codex 安装；本轮未重装/未联网）；worker 为独立进程，不常驻、不安装重模型。
- 湖南钢铁样本 `hunan-steel-2026.pdf`：1 页、真实表格、4 家企业（湖南华菱湘潭钢铁、衡阳华菱钢管、冷水江钢铁、湖南华菱涟源钢铁），`status=done`、`coverage=100%`、页码 1、行列/单元格可核对。
- methane 方法学 `methane-methodology.pdf`：53 页；测试按 `max_pages=2` 运行，`pages_total=53`、`pages_processed=2`、`status=partial`、`partial_reason=page_limit`、`coverage≈3.8%`；不推断零企业。

### 6.2 资源与安全边界

- 文件 ≤ 20 MB；页数 ≤ 500（默认 200）；超时 5–180 秒（默认 120 秒）；输出 ≤ 16 MB、表格 ≤ 2000、单元格 ≤ 200000；
- 单进程并发 1；已有任务运行时返回 409；
- 输入路径先 `resolve + realpath`，只允许 `<db目录>/official-originals`；测试样本根仅在 `CCER_PDF_TABLE_ALLOW_SAMPLES=1` 时开放；拒绝 `../`、符号链接越界、非 `.pdf`、目录、空文件、超大文件；
- Python 子进程只传白名单环境变量（PATH/SystemRoot/TEMP/PYTHONPATH 等），不传应用密钥；
- 失败/超时/损坏 PDF：任务记 failed/partial 与真实错误，不删除原件、不覆盖既有正文、不写伪造表格；成功才写逐页/表格行。

### 6.3 coverage/partial 与扫描空页

- `pages_total` 来自 pdfplumber 真实页数；`pages_processed` 是实际处理页；`coverage_ratio = pages_processed/pages_total`；
- `partial_reason`：`page_limit` / `page_failures` / `no_text_layer_or_tables` / `max_tables` / `max_cells` / `timeout` / `output_too_large` / `worker_error`；
- 扫描/空白页标 `status=empty`、`has_text_layer=0`、`enterprise_conclusion=unknown_no_text_layer`、`zero_enterprises_claim_allowed=false`；
- 页面提示“扫描空页不等于零家企业，需要 OCR/人工核对原件”。

### 6.4 后台入口

「后台管理 → 公开信息智能化」新增：

- 索引状态、最近构建/完整构建、有限批重建；
- PDF worker 状态/限额/受限根、已归档原件候选、受限路径输入、最多页数、执行按钮；
- 任务表：文件、状态、页/覆盖、表格/行、partial/错误原因、详情；
- 详情抽屉：逐页文本层/表格/行/状态，以及最多 5 张表的行列与单元格文本。

普通用户无法访问 `/api/v2/admin/pdf-tables/*`；服务层再次校验 `role=admin`。

## 7. 第一阶段独立验收修正

### 7.1 日期语义

- `publish_date` 只接受同句、相邻（≤40 字符，前置）的明确标签：`发布日期/发布时间/发布日/公布日期/公布时间/生成日期/成文日期/印发日期/公开日期/发文日期`，或紧邻的 `发布于/生成于/公布于`（≤8 字符）；
- 纯落款 `2024年12月31日`、`2024年12月31日印发`、`2024年12月31日发布` 均不接受；
- `effective_date` 只接受 `施行日期/实施日期/生效日期/施行时间/实施时间/生效时间`，或日期后紧跟 `起施行/起实施/起生效`（可带“自/从”）；
- “本通知自印发之日起施行”没有具体日期，不生成生效日期；
- 规则抽取正则同步收紧，不再用裸“发布/印发”作为标签。

### 7.2 阈值单位/方向

- 解析字段值中的数字、方向、单位，并在引句中寻找“同一数字 + 同单位”的出现位置；
- 字段值有单位而引句无对应单位、引句有单位而字段值无单位、单位不一致 → 拒绝；
- 引句有方向而字段值无方向、字段值有方向而引句无方向、方向不一致 → 拒绝；
- 方向归一：`不超过/不高于/≤/<=`、`不低于/≥/>=/以上`、`低于/小于/<`、`高于/大于/>`、`以下/及以下/<=`；
- 例：`quote="低于8%"` 不支持 `value="8吨"`、`value="高于8%"`、`value="8%"`（丢失方向）；支持 `value="低于8%"`。

### 7.3 地区/行业“提及”

- `FIELD_DEFS.region/industry` 标签改为“仅正文提及”，增加 `mention_only=true`、`scope_warning`；
- `getFieldEvidence` 每条字段返回 `mention_only/scope_warning`；
- 内容详情字段表显示“仅正文提及”徽标与说明；
- 模型提示词明确：region/industry 只表示提及，不代表官方适用范围，不得据此推断项目合格；模型抽取不是官方确认。

## 10. 已知限制

1. `content_item` 入库/更新在索引完整构建后即时单条刷新；政策/方法学/项目/CEA/因子/企业名录仍等每日/后台批次刷新。索引未完整构建时统一检索自动回退 legacy，不会把半套索引当最新文本宣称。
2. 中文切分是双字/单字，不引入 jieba 等词典分词；少数跨词短语可能过匹配，精确编号与筛选仍需以库内实体/原文为准。索引 offset 上限 10000，更多结果需缩小关键词。
3. 关注信息流扫描最近 300 条内容、最多 20 条规则；不是全历史推送，也不发送邮件/第三方消息。地区/行业命中是正文或元数据提及，不是官方适用范围。
4. PDF worker 不 OCR 扫描页：扫描/空白页只标 `no_text_layer/empty`，`enterprise_conclusion=unknown_no_text_layer`；需要百度 OCR 或人工核对，不能据此得出“零家企业”。
5. PDF 解析在管理员请求内同步等待 worker；已设 120 秒默认超时与单并发。53 页全量、超大表格或极慢磁盘可能返回 partial/timeout，需缩小页数或分批。
6. PDF 结果/输出 JSON 存库；暂未做历史任务自动清理/配额回收，后续可按保留期清理，不影响本轮真实解析。
7. 真实联网、真实付费模型、全平台浏览器/可访问性、云端迁移演练、部署与 Git 推送本轮均未执行，由 Codex 独立验收；本轮未读取密钥/环境变量内容，未读取 `data` 下数据库。
