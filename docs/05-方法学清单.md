## 本清单的性质与确认要求

本清单是**方法学目录基线**，须由领域专家逐条确认后方可用于正式项目筛选。确认要点：

1. **编号与名称**：以生态环境部发布通知为唯一权威来源；第 9–17 项仅有主管部门答记者问口径，
   编号尚未从发布通知核实，须由研究员在[全国温室气体自愿减排注册登记系统](https://ccer.cets.org.cn/)逐条核对后补录。
   系统**不推测**编号；未核实编号的条目仅供检索与观察，不列为可申报候选。
2. **发布/生效日期**：须与发布通知一致。修订征求意见稿的生效日期必须为空。
3. **规则卡状态**：标「已建」的方法学已有结构化规则卡，可执行条件检查；标「未建」的仅供参考。
4. **计算插件状态**：标「已注册」的方法学可执行情景初算，但其中的方法学专属系数仍为占位值，
   须由领域专家逐项确认（见[领域专家确认清单](./12-领域专家确认清单.md)）。
