基线观察：

- 顶栏和导航为白色，和“深绿色导航”的确认方向不一致；导航用 Unicode 字符作图标，权重不一。
- 导航 `top: 77px` 是硬编码 sticky 偏移；浏览器实际高度变化时有遮挡风险。
- 总览 6 张同形指标卡 + 多个同形卡片，层级主要靠卡片边框，标题只有 18px，扫读起点不强。

- 登录截图在截图时刻只显示背景，卡片和标题均不可见。原因是入场动画依赖 `opacity: 0` + `both`，且截图时点较早；这不满足“默认内容可见”。背景另有持续呼吸和无限轨道动画，也不符合克制动效要求。
- AI 问答区在总览底部但视觉上和普通数据卡相同；输入、来源、聊天层级不够明确。
- 后台页签多、信息密度高，但没有统一的表单/状态块层级；`toast('...', 'error')` 甚至没有对应颜色。
- 旧 `summary-block`、`verify-box` 使用 3–4px 左色条；本轮按 craft floor 改成整块语义边/底色。

## 3. 设计取舍

### 3.1 视觉系统

- 保留森林绿识别，但把深绿交给**顶栏、主导航、问答抬头**三处结构。
- 底色 `#f3f5f0`，阅读面 `#fffdf8`；摘要、表头、说明用浅雾绿 `#edf3ed`。
- 青柠 `#d7e69a` 只出现在品牌字标、当前导航细线、登录标点和少量摘要标签。
- 卡片只保留 1px 边框，不再每张卡加宽软阴影；只有抽屉、登录卡和 toast 使用层次阴影。
- 总览 6 个指标合并为一块三列指标板，用分隔线和留白分组，避免六张同形卡。
- 列表从“每条一张小卡”改成细线分隔的阅读行，摘要仍保留，但不再嵌套卡片。
- 中文优先使用本机 Noto Sans SC / 思源黑体 / 微软雅黑字体栈；登录标题用本机 Noto Serif SC / 宋体栈，不引用任何远程字体。

### 3.2 页面结构

- 新增共享 `page-head`：页面标题、页面范围说明、数据截至日和当前视图（公开信息/管理员）；手机隐藏重复的数据/视图块，保留顶栏已显示的数据日期。
- 顶栏改为深绿：品牌、数据状态、用户身份分行收敛；窄屏保留数据日期与身份，隐藏“内容条数/最近同步”等次要信息。
- 主导航改为深绿 sticky `top: 0`，去掉硬编码的 77px；所有 8 个模块和基于权限的后台入口保留。
- 导航图标全部改为同一套 24×24、1.7px 描边的内联 SVG；空态/错误态图标也改为线性 SVG。
- 登录入口重做信息层级：保留既有绿色能源背景、遮罩和注册/登录功能；卡片改为暖白实底 16px 圆角，去掉玻璃模糊和无限动画，保证首帧可见。

### 3.3 阅读与交互

- 表格升为 13px / 10px 内边距，表头 sticky、可键盘排序、`aria-sort` 同步；内容表保留合理 min-width，在自身容器横向滚动。
- 表格标题按钮只在 hover/focus 时出现下划线，避免长列表持续“满屏链接”。
- 行情涨跌在表格中用 `+/-` 与 `.delta-up` / `.delta-down` 双重表达；状态仍使用 ok/warn/danger。
- AI 问答成为页面唯一深色功能区：深绿抬头 + 暖白正文 + 浅雾绿范围说明；空态提供三个基于真实功能的示例问题，点击只填入输入框，不自动发送、不生成虚假对话。
- 表单、按钮、页签、提示、toast、空态、错误、禁用态统一到 tokens；新增键盘焦点环、跳转到主要内容与 `role=log`。抽屉保留 `role=dialog`，未宣称完整焦点陷阱。
- 所有动画 120–200ms，登录只保留一次落位；`prefers-reduced-motion` 下关闭动画和平滑滚动。
