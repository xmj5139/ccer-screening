# 首页地图修复记录

2026-10-20｜DSH 实施，对应 `docs/70-首页名录地图与刷新修复要求.md`。

本轮只改首页省域地图与其刷新链路；保留现有浅色绿色设计、登录/权限、项目/排放/CEA 其他模块。未写真实库、未读取凭据、未部署、未推 GitHub。Codex 仍负责来源审计、独立核验和云端更新。

## 1. 完成内容

### 1.1 名录指标

`region-map-svc` 新增指标/视图 `ets_entities`：

- 名称“CEA纳管企业名录”，单位“家”，范围 `cea_entity`。
- 来自 `cea_entity`，按统一社会信用代码 + 名录年度去重；未披露信用代码的条目按名称参与去重。同一主体多行业、多出处只计 1 家。
- 未收录省份返回 `null`，不补 0；`missing=true` 与灰色斜纹一致。
- 新增 `list_year` 查询参数与 `list_year_options`，默认最新实际名录年度；名录年度不使用排放 `year`，`year` 与 `dataset` 在名录视图被拒绝。
- 旧 `projects` / `region_co2` / `national_ets` 的数值、单位、数据集、年度和来源语义保持不变；新增字段只做补充。

### 1.2 省份出处与覆盖

- 每个省份的 `ets_directory.sources` 返回该省该名录年度全部可追溯出处（`source_code`、`source_url`、数量、采集日期），来源取 `cea_entity_membership`，缺失成员表时回退主体行字段；不再用全库最后一条来源替代其他省份。
- 省份详情显示“仅取得……行业名单；……行业名单尚未取得”，广东当前仅发电、河南当前仅发电/钢铁，均可在详情中看到；总览摘要明确“本平台已收录，非全国/全省完整数量”。
- `directory_as_of` 与排放日期分离；总体、分省详情和 CSV 都单列名录采集截止日。
- CSV 增加 `ets_source_urls`（全部省内出处）、`ets_source_codes`、`ets_source_count`、`ets_sectors`、`ets_missing_sectors`、`ets_coverage_note`；`value`/`unit`/`ets_directory_year` 与页面同源。

### 1.3 首页地图与入口

- 地图新增第四个视图“CEA纳管企业名录”，着色、排名、右侧详情、总量、覆盖地区数、图例、tooltip 与导出统一使用当前选定指标。
- 名录图例不出现“0 家”，改为“未收录（不补 0）”；tooltip 明确“未收录”或“本平台已收录，非全省完整数量”。
- 默认仍进入公开 CCER 项目图，但在卡面上方新增名录提示带，显示“最新已收录纳管企业 N 家 / 覆盖 N 个省级地区 / 名录 2026 年”，并提供 `#/overview?map=ets_entities&list_year=2026` 入口。
- 从该入口进入时 `overview` 直接请求 `metric=ets_entities`，地图初始视图即为名录热力图。
- 省份联动统一使用规范全称，并带 `tab=entities`、`list_year`；CEA 名录页现有全称/简称别名组可正确过滤。

### 1.4 刷新

- 卡头新增“刷新数据”按钮和“最近成功读取”时间。
- 页面可见时每 60 秒发起一次只读 `GET`；标签页从后台恢复可见时立即刷新一次。
- 刷新保留当前视图、名录年度/排放年度、数据集、选中的省份、区域分组和项目筛选。
- 失败时保留上次成功数据，显示 `role=alert` 的失败提示、失败原因、上次成功时间和“重试”按钮；切换视图失败时旧图仍在，但提示明确写出“新视图加载失败，仍显示上次成功数据”，不会伪装成新视图成功。
- 请求重叠由 `refreshInFlight` 拦截；旧请求由递增的 `loadSeq` 与 `disposed` 守卫，不会覆盖新视图或更新已销毁的 DOM。
- `overview` 返回清理函数；`app.js` 在每次重新渲染/路由离开前调用，地图销毁时清理 60 秒定时器、`visibilitychange` 监听和根节点事件委托。待处理请求无法真正 abort，因为现有 `api(path, {method, body, raw})` 不支持 `AbortSignal`；未发明未传递参数，改用序列号与销毁守卫。
- 数据未变化时刷新只更新读取时间，不整卡重渲染；数据变化时才更新地图卡。

## 4. 未完成与限制

1. 名录仍只有当前已导入的 14 个省级地区；广东仅发电、河南仅发电/钢铁。其他省份的行业完整性未证明，未补采、未用第三方补齐。
2. 省份没有记录时保持 `null`；旧 `national_ets` 视图的 `ets_directory.count` 为兼容既有 API 仍在“该名录年度存在”时返回 0，新 `directory.count` 才使用 `null`。两者在页面上分别按“未收录/未取得”处理，但调用方需注意这个兼容差异。
3. 出处来自已有 `cea_entity_membership`/`cea_entity` 字段；若历史行既无来源链接也无来源代码，只能保留空出处，不生成 URL。
4. 自动刷新只刷新地图卡，不重载顶部指标板和整页；这是为了避免 60 秒重渲染打断阅读。页面顶部“最近成功同步”仍由现有全局状态逻辑维护。
5. 现有 `api` 不支持 `AbortSignal`，因此网络请求本身不会中途 abort；通过序列号和销毁守卫保证过期响应不更新 DOM。
6. 未做真实浏览器 1440/1366/768/390/360 交互和截图验收；需 Codex 独立核验。未部署云端、未更新生产库、未提交 GitHub。
7. 名录年度选项来自实际 `list_year`；允许当前年 +1，以容纳提前发布的下一年的名单，但仍只展示库内实际存在的年度。
8. CSV 的 `ets_source_urls` 多个链接以 ` | ` 分隔；单格过长时由表格/表格软件处理，不截断来源。
9. 环境说明：本会话的工具列表没有 GraphFlow MCP 工具（`mcp__graphflow__*`），无法按技能要求先调用 `graphflow_context`；已按 docs/70 直接读取指定文件，未启动其他代理代读。Codex 的来源审计、独立核验和云端更新不在本轮执行。
