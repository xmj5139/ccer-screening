## 页面验收

使用独立临时库、无真实服务配置、无定时器的本地 8930 服务验证：

- 管理员登录、RSS/索引/PDF 后台入口、有限批索引刷新可操作，刷新后待更新队列清空。
- 关注规则保存后展示命中原文；标为已读后未读从 1 变 0。切换普通用户看到自己的 0 条规则，不能看到管理员的规则。
- 普通用户导航没有后台入口；直接访问后台地址被前端拦截，服务端 401/403 由 HTTP 回归另行验证。
- 正文详情展示逐字引句、原文高亮、规则/模型来源、附件与版本。
- 企业名录进入档案，展示规范代码、年度行业地区、公开来源和历史；不以名录数推算企业排放。
- FTS 搜索能返回正文、政策、方法学及原文链接；无模型时显式显示“已回退关键词检索”，没有假装智能成功。
- 桌面和窄屏检查未见页面级横向溢出；数据表在自身容器内横向滚动。浏览器错误日志为 0。保留原绿色风格与一级导航结构。

截图与原始回执在本地验收目录保存；临时账号、关注规则及样本不进入云端生产库。

## 发布边界与限制

- 每日任务有次数、条目、时间和单并发边界；不以无限循环替代来源证据。
- 大量源数据同时变更时，检索有界处理 dirty 队列；尚未处理完会明确回退，不能把旧 payload 当最新。
- 字段引文动作与详情本轮主要接入研报动态 `content_item`；其它公开类型继续既有原文、摘要与检索，未宣称所有实体均有新增字段抽取 UI。
- PDF worker 是轻量 pdfplumber；扫描件仍依赖已有 OCR/管理员原件上传，不承诺所有 PDF 自动识别成功。
- CEA/CCER 候选数据只用于差异报告，不写正式行情；未知标的、未来交易日、不明确单位等标 unsupported。别名与企业关系只采用有来源的记录。
- 本轮不安装常驻重模型、Docling 全套或 sqlite-vec；不推 GitHub，不改变云端账号/API 配置。

## 实现依据

开发设计 86 和 ADR-006/007/008 保存取舍。库的行为依据官方资料：

- [SQLite FTS5](https://www.sqlite.org/fts5.html)：使用 FTS5、保留短语词位、受控 MATCH；中文短词另外预切分。
- [pdfplumber 官方仓库](https://github.com/jsvine/pdfplumber)：读取原生文本层与表格，扫描件需要另行 OCR。
- [Trafilatura 官方文档](https://trafilatura.readthedocs.io/en/latest/corefunctions.html)：正文清理与可选表格提取。
