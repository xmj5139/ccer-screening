# 全国碳市场企业名录补采要求

日期：2026-10-20。用户要求在网上收集碳排放纳管企业名录。Codex负责搜索政府原文、下载原件、逐表规范化及真实数据核验；DSH负责已有采集器的必要修复。

## 实施范围

1. `collectCeaEntities`当前默认查询来源后固定`list.slice(0,4)`，后续来源永久饥饿。保持每批最多4个和共享总deadline/并发限制，对默认来源按未尝试优先、last_attempt_at最旧优先、priority与code稳定排序。显式codes按指定顺序，不擅自轮换。不要新增计划任务、扩大单次预算或解除SSRF限制。累计处理标记要如实，不能宣称剩余来源已完成。
2. 引入 `src/data/cea-entity-public-sources.mjs` 中 `CEA_ENTITY_PUBLIC_SOURCES` 到既有 CEA_SOURCES。该文件由Codex持续补入真实来源；DSH只负责接线，勿覆盖或填猜测URL。现已有福建2026来源保留。来源默认仅正式公布的全国碳市场名单；地方试点、仅报告核查企业、拟纳入/征求意见清单不进正式目录。
3. 针对真实HTML表格和PDF提取文本完善 `parseEntityRows`。样本可读`data/backups/cea-directory-20261020/raw/`（*.html、*.pages.json）。应正确识别企业名称/18位信用代码/地区/行业，不能将行业与备注拼进名称，不能把网页导航发布日期或通知引用的2025年误作2026名录年度。年度须在名录标题/该表标题或已核实来源元数据中明确；冲突返回缺口，不猜测；不要把行业分类代码2511误当实际纳管类别（自备电厂可在发电名单中）。多表按各表标题行业，文件单一行业可以由来源登记明确sector作补充。缺代码留空并保留原始值，校验位异常只标注，不修改原文或编造代码。
4. 对可信正式来源中的1~2行小行业名单允许正确解析（例如宁夏钢铁、四川铝冶炼），仍拦截采购公告/无名录依据的非企业行。不要靠放宽全局minRows来收录任意非名录。
5. 采集同一原件hash未变时复用已完成结构化结果；不得以弱解析覆盖既有完整企业字段。已有cache契约保留。不得因取不到数据删除历史企业或将其标为退出。
