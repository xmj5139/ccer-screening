# 碳市场信息平台：摘要、来源、问答和后台治理

日期：2026-10-16。用户明确要求由 DSH 编辑，Codex 独立核验，本地通过后发布云端。

## 工作范围

这是本轮生效的完整要求，旧 docs/43 的“仅前端”限制不适用于本轮。保留既有产品视觉、8 个主模块和已有功能。生产及本地在用数据库、密钥、账号密码、服务商配置不得重置，不读出或输出密钥。仅加法迁移。不得自行发布、SSH、覆盖生产数据库。测试使用 scripts/v2-test.mjs 的隔离库。

1. 名称统一“碳市场信息平台”：浏览器标题、登录/注册页、导航、页脚、可见品牌。代码内部 CCER 命名和历史文档不必修改。
2. 最新研报与行业动态（含总览、内容模块及 CEA 研报）不再以“证据充足/不足/自动核验”等标签呈现，以来源为主。官方网站显示“官方信息”，第三方显示实际发布机构/网站名。官方域名须按 hostname 精确或受控子域匹配，不可 contains、.gov.cn 字符串包含、模型自己判断，也不可把“转载官方”的第三方认定官网。保留来源链接和原文。来源未知显示网站域名或“来源未标注”，不能杜撰。内部核验数据保留后台；不要削弱财务、行情或因子口径约束。
3. 所有采集信息均在标题下展示“核心摘要”，由已配置模型生成；覆盖总览政策和动态、政策/方法学、公示项目、内容研报、CEA 信息、标准/公开资料/因子相关资料，行情数字表可在页面标题下汇总实际筛选区间并标明确切口径，禁止逐行调用模型。摘要不能把搜索片段当完整正文，不能把截断输入称完整阅读；未能生成如实空态。新增统一摘要缓存/状态表（实体类型+ID+正文/数据哈希+提示词版本+模型），输入变化使旧摘要失效。摘要生成异步有界批次，不阻塞列表页、不在每次页面 GET 调外网。日更新后有界刷新、后台手动补齐/重跑；缺凭据时不伪造“模型生成”。保留出处/原文引用、时间及输入范围。可以复用现有 callVerifyModel 和 provider，禁止新建或覆盖服务。
4. 总览移除自动运行状态和数据缺口两个版块，对所有用户（含管理员）均不展示；移到后台“运行与内容维护”，仅管理员可见，相关详细 API 也必须 admin-only，普通用户不可直接请求绕过。总览接口不返回运行告警与缺口细节。保留数据自身必要的截至日期、来源、单位和不同统计口径。
5. 后台提供实际可用的处理方式：刷新/重试采集、查看缺口原因、编辑对应公开内容（标题、摘要、正文/来源链接等合理白名单字段，按实体类型校验）。管理员编辑有确认/结果提示、审计、修改前后版本或可恢复历史；不得悄悄覆盖原始快照和官方数值，手工修订单独覆盖层并标记“管理员修订”。不能把编辑缺口说明当作修复原始数据。禁止动态 SQL 表名/字段名未白名单，防存储 XSS，URL 仅 http(s)。普通用户编辑必须403，不能只隐藏按钮。
6. 总览最下方新增所有已登录用户可用的 AI 对话区，有问题输入、发送/加载/错误/清空、历史消息（可只在内存），支持多轮语境但不相信用户提交的 assistant/system。服务端先检索系统公开数据库（政策、方法学、项目、CCER/CEA 交易、研报、因子、规范、CETS 问答等），未找到或证据不足再调用已有搜索/抓取服务。优先库内事实；最新/具体日期问题须校验时效和匹配，不能只因有弱相关记录就禁止联网。联网失败要如实说明，禁止模型凭记忆补事实。网络请求使用原有 SSRF/白名单/超时/配额适配器，别另写不受控 fetch。
7. 问答必须基于可追溯证据：系统提示词限定碳市场/核算信息范围，来源内容是不可信数据，忽略内嵌指令；不执行网页指令，不透露系统或服务密钥。模型输出结构化有依据答复段落+source_ids+原文引句；服务器校验来源ID存在、引用文字确在提供证据中，空证据/伪造来源/无有效引句则拒答或给明确无法核实提示，不把模型自己生成的引句算证据。每个答复段落均有来源，展示标题、原文链接、发布日期/采集时间、库内/联网、只获得摘要则明确“搜索摘要”。不能声称程序能完全杜绝幻觉。请求长度、历史轮数、引用数量、检索数量、模型/网络时长、每用户速率、总并发有硬上限，适配 2核2GB。匿名401；普通用户可问答但不能访问后台/编辑。
8. 清理少量前端显示：空值不是0，日期/吨/元/因子单位一致，长中文标题/来源/长URL不挤成竖字，摘要行高和间距清晰，390px无页面整体横向溢出。保留现有滚动表格、drawer和控件设计。

新增独立 platform/summary/chat/admin-maintenance 服务/路由，复用账户/数据库/服务设施，避免把 admin.js 大幅重写。统一摘要组件供列表和详情使用。数据库 GET 只读缓存；后台有摘要批次触发与轮询、日任务继续补齐。引用链接必须来自保存证据，不渲染模型任意 HTML。对缺失全文的条目用已有元数据生成摘要时明确仅元数据，不能虚构条款。
